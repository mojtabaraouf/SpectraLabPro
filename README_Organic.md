# New Features Added: Organic, Biosignature and Lunar Analogue Detection Module

## Overview

The SpectraLab Organic Biosignature Suite has been expanded beyond traditional CO₂ and H₂O monitoring to provide a comprehensive UV–VIS–SWIR spectral analysis platform for:

* Organic compound detection
* Biosignature screening
* Lunar and planetary analogue studies
* Carbonaceous material characterization
* Mineralogical mapping
* Astrobiology feasibility investigations

The software now supports spectral interpretation from **196 nm to 2500 nm**, covering Deep UV, UV, Visible, Near Infrared (NIR), and Short-Wave Infrared (SWIR) wavelengths.
